# Lesson 01：自回归语言模型基础

## 核心理解

自回归语言模型可以先理解为“根据已有文字进行自动补全”的模型。

给定：

```text
The capital of France is
```

模型先预测下一个 Token，可能倾向于：

```text
 Paris
```

然后把预测出的 Token 接到原文本后面，再预测下一个 Token。

过程可以概括为：

```text
已有文本
→ 预测下一个 Token
→ 把 Token 接到文本后面
→ 再预测下一个 Token
```

“自回归”表示每一步都依赖前面已经存在的内容，并且从左到右生成。
